# Detailed Reports Landing Page

A responsive, single-page marketing site for **Report Hub** — a detailed-reports service. Bold hero section ("Data-Driven Reports for Every Need"), feature cards, report categories, and call-to-action sections, all in one static page.

## Features

- Hero section with headline, sub-copy, and CTA buttons
- Feature cards highlighting report types (market, finance, research)
- Category showcase grid
- Responsive layout for mobile, tablet, and desktop
- Zero dependencies — pure HTML + CSS (Tailwind-style classes via CDN)
- Fast, SEO-friendly single-file site

## Tech Stack

- HTML5, CSS3
- Tailwind CSS (CDN)
- Static — no build step, no backend

## Quick Start

Just open `index.html` in a browser:

```bash
git clone https://github.com/girishlade111/Detailed-Reports-Landing-Page.git
cd Detailed-Reports-Landing-Page
open index.html   # or double-click the file
```

Or serve locally:

```bash
npx serve .
```

## Customization

All content lives in `index.html` — edit the headline, feature cards, and colors directly. No build step needed; changes go live on refresh.

## Deployment

Static site — deployable anywhere:

- **GitHub Pages** — enable Pages on the `main` branch, root path
- **Cloudflare Pages / Netlify / Vercel** — point at this repo, no build command needed
